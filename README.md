# BATCRadar

Moving map / EFB for Microsoft Flight Simulator with live traffic from BeyondATC.

## Run (development)

MSFS and BeyondATC should be running.

1. Install [Python 3](https://www.python.org/downloads/) (add to PATH).
2. Double-click `START.bat`.
3. Open the PC or tablet URL printed in the console.

Traffic and ownship come from BeyondATC (port 41717). SimConnect is used for procedures and as fallback if BATC has no player aircraft.
